# 🦠 Peta Risiko Persebaran ISPA (ARI Spread Risk Map)

Platform pemantauan spasial dan simulasi prediktif risiko Infeksi Saluran Pernapasan Akut (ISPA) berbasis lingkungan untuk mendukung mitigasi kesehatan masyarakat.

## 🚀 Fitur Utama

Beranda & Dokumentasi Sistem (`index.html`): Informasi latar belakang, definisi klinis ISPA, dan tujuan platform.

Peta Spasial & Generator Simulasi (`generator.html`): Peta interaktif berbasis `Leaflet.js` dengan filter wilayah dan kalkulator prediktif berbasis parameter AQI serta kepadatan penduduk.

Profil Tim Pengembang (`about.html`): Pengenalan kolaborator lengkap dengan tautan media sosial dan pengatur bingkai foto interaktif.

Ekspor Data Spasial: Kemampuan mengunduh ringkasan dataset hasil simulasi ke dalam format .csv.

##🛠️ Teknologi yang Digunakan

Frontend: HTML5, CSS3, [Bootstrap 5](), Bootstrap Icons

Mapping Engine: `Leaflet.js & CartoDB Basemaps`

Logika & Pemodelan: JavaScript (ES6+), scikit-learn (konsep pembobotan data tabular)

## ⚙️ Cara Menjalankan dan Mengakses Web

Clone atau unduh repositori ini ke komputer Anda.

Buka peramban (browser) dan jalankan berkas `pages/index.html` secara langsung, atau gunakan ekstensi Live Server di VS Code.

Anda juga dapat mengaksesnya melalui [link web.]() 


# English

# 🦠 ARI (Acute Respiratory Infection) Spread Risk Map

An environmental-based spatial monitoring and predictive simulation platform for Acute Respiratory Infection (ARI) risks, designed to support public health mitigation efforts.

## 🚀 Key Features

Home & System Documentation (`index.html`): Background information, clinical definitions of ARI, and the platform's objectives.

Spatial Map & Simulation Generator (`generator.html`): An interactive map built with `Leaflet.js`, featuring regional filters and a predictive calculator based on Air Quality Index (AQI) parameters and population density.

Development Team Profile (`about.html`): Introductions to the collaborators, including social media links and an interactive photo frame tool.

Spatial Data Export: The ability to download simulation dataset summaries in .csv format.

## 🛠️ Technologies Used

Frontend: `HTML5, CSS3, Bootstrap 5, Bootstrap Icons`

Mapping Engine: `Leaflet.js & CartoDB Basemaps`

Logic & Modeling: JavaScript (ES6+), scikit-learn (tabular data weighting concepts)


## ⚙️ How to Run and Access the Web Application

Clone or download this repository to your computer.

Open your web browser and run the `pages/index.html` file directly, or use the "Live Server" extension in VS Code.

You can also access it via [web link.]()
